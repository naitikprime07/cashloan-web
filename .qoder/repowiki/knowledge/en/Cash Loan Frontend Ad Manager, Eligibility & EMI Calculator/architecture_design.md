The module is a flat collection of self-contained IIFE modules that attach themselves to `window` globals and coordinate via shared configuration objects rather than importing each other.

- Configuration layer: `ad-config.js` exposes `window.AdConfig` as the single source of truth for all ad placements (display, interstitial, anchor) keyed by logical IDs and mapped per page via `PAGE_AD_MAP`; `pixel-config.js` exposes `window.PIXEL_CONFIG` for Meta Pixel settings.
- Bootstrap / infrastructure: `gam-loader.js` lazily loads GPT (`securepubads.g.doubleclick.net/tag/js/gpt.js`) once and exposes `window.GAM.init()` returning a Promise; `pixel-loader.js` lazily loads Facebook's `fbevents.js` and uses IndexedDB plus optional Web Locks to emit at most one PageView per browser profile.
- Orchestration layer: `ad-manager.js` owns the full ad lifecycle — it reads `AdConfig`, builds slot records in a `Map`, defines display/out-of-page slots via `googletag`, listens to GPT events (`slotRequested`, `slotRenderEnded`, `impressionViewable`), enforces state transitions (`queued` → `defined` → `loading` → `ready`/`no-fill`/`consumed`/`destroyed`), handles bottom-anchor spacing via CSS custom property `--anchor-space`, and intercepts clicks on `[data-interstitial-trigger]` to show native interstitials.
- Feature pages: `app.js` drives the multi-step dropdown wizard, contact form (POST or mailto fallback), back-button history, and summary rendering; `eligibility.js` implements the loan-eligibility estimator with per-loan configs (personal/auto/student/business/payday/home/gold), FOIR-based capacity math, and renders an apply CTA wired to an interstitial trigger; `emi.js` is a standalone EMI calculator with synchronized range/text inputs and a donut chart.
- Compatibility shims: `interstitial-ad.js` and `bottom-anchor.js` are thin entry points that simply call `AdManager.init()`, preserving legacy script includes.

Dependency direction is strictly one-way: feature scripts depend on `AdConfig`/`PIXEL_CONFIG` and may invoke `GAM`/`AdManager`/`CashLoanPixel`, but never the reverse. There is no build step — files are loaded directly by HTML.
